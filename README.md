# Python_data_analysis
Data Analysis using Python
This project explores a dataset of over 7,000 movies from 1980 to 2020 to uncover what factors most strongly influence a movie's financial success. By performing data cleaning, categorical encoding, and correlation analysis using Python, pandas, and seaborn, the project tests common assumptions about movie profitability—specifically evaluating whether high production budgets or user popularity ratings correlate more strongly with gross earnings.
